# Documentation map

Read all docs in numeric order. `01_PRODUCT_SCOPE` defines what is in/out of scope; `02_ARCHITECTURE` fixes offline components; `03_DATA_MODEL` and `04_DATA_DICTIONARY` fix grains and relationships; `05_DATA_CONTRACTS` and `06_INGEST_LINEAGE` define correct source handling; `07_RULE_ENGINE`, `08_GOLDEN_FIXTURES`, `09_REASONABILITY_RULES`, `10_REMIT_RECONCILIATION`, `11_SOURCE_CONTROLS`, and `12_SNAPSHOT_COMPARISON` define correctness; `13_EXCEPTION_REVIEW`, `14_AUDIT_DB`, `15_CLI`, `16_REPORTS`, `17_DEFINITION_OF_DONE`, `18_TEST_PLAN`, `19_PRIVACY_SECURITY`, `20_ERROR_HANDLING`, `21_SQL_CHECKS`, `22_PERFORMANCE`, `23_DOCS_AND_PORTFOLIO`, `24_IMPLEMENTATION_PHASES`, `25_INTERVIEW_GUIDE` complete the contract.

The generator and 10 fixture tests are *starter* checks only. Codex must build a separate application test suite and demonstrate genuine end-to-end completion.
